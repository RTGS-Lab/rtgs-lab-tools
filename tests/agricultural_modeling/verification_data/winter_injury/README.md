# Winter Injury Model Verification Data

Reference data for validating the Python winter injury (LT50) model against
the original R implementation by Byrns et al. (2020).

## Files

- `r_reference_output.csv` — Output generated by running the current R model
  (`wcsmR2.R`) via `deSolve::ode(method='euler')` with Norstar parameters
  (LT50c=-24, vernReq=49, minDD=370, photoCoeff=50, photoCritical=13.5).

- `wcsmR2_Data_crownTemp.csv` — Crown temperature input data (from the WCSM
  Shiny app repository).

- `wcsmR2_Data_daylength.csv` — Daylength input data (from the WCSM Shiny
  app repository).

- `kleefield-output.csv` — Legacy output from an older version of the R model.
  Note: this was generated by a prior version with a broader vernalization
  temperature range and differs from the current R code.

## Source

The R model is from:
  Byrns, B.M., Greer, K.J., & Fowler, D.B. (2020). Modeling winter survival
  in cereals: An interactive tool. Crop Science, 60, 2408-2419.
  https://github.com/byrn-baker/wcsm-usask (GPL-3)

These CSV files are model outputs and input data, not source code.
